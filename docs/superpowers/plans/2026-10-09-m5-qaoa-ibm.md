# M5 — QAOA on IBM Quantum: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add CVaR-QAOA to the M4 bench harness. It runs noiseless, under a simulated IBM noise model, and on real IBM hardware behind a hard-failing quota ledger. Then run the M5 study and record its result.

**Architecture:**
- **Training:** QAOA angles are trained once per QUBO by an exact numpy statevector simulator. The cost layer is diagonal, so it is one elementwise phase. The angles are cached in a file directory beside the store.
- **Sampling:** three `QuboSampler` subclasses sample at those angles: numpy noiseless, Aer with a fake-device noise model, and bits collected from IBM. Decoding, feasibility and scoring are therefore the M4 samplers' own.
- **Process pool:** quantum tasks run in their own pool phases with fewer workers.
- **Hardware lane:** IBM jobs run one at a time in the main process. The lane checks a simulator gate and the quota ledger, records each job id before waiting, and never repeats a stored hardware task.

**Tech Stack:** Python 3.11, numpy, scipy (COBYLA), qiskit 2.5, qiskit-aer 0.17, qiskit-ibm-runtime 0.50 (executor `Sampler`, fake backends, local mode), DuckDB, polars, typer, pytest.

**Spec:** `docs/superpowers/specs/2026-10-09-m5-qaoa-ibm-design.md`

## Global Constraints

- QUBO variables above `max_qubits` (default 28) are never planned; full `qaoa_noisy` runs above `noisy_max_qubits` (default 20) are never planned.
- The quota cap is at most `QUOTA_CEILING_S = 300.0` seconds per rolling 28 days. Config may lower it, never raise it.
- Every IBM job is submitted with `max_execution_time = floor(min(per_job_cap_s, cap − used))`. The ledger refuses a job when `cap − used < min_job_s`.
- A job id is written to the ledger and the store **before** the runner waits on the job.
- A stored `qaoa_ibm` task (`ok`, `pending` or `error`) is never re-submitted under any commit, unless `--repeat-hardware` is given.
- No test touches the network. The IBM path is tested in local mode against fake backends.
- The IBM token is never written to the repository or to any store.
- Infeasible samples are never repaired (parent spec section 6.5); QAOA reuses `run_sampler`.
- Commits are under the repo-local identity (cedric). Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Nothing is pushed.
- Windows: run Python as `.venv/Scripts/python.exe`. Never invoke bare `python`.

`src/quantic/solvers/quantum/ising.py`:

```python
"""The QUBO as an Ising operator, for a gate-model circuit -- M5 design section 5.1.

``x_i = (1 - z_i) / 2`` turns ``x'Qx + c`` into ``sum h_i z_i + sum J_ij z_i z_j
+ offset``. A measured bit ``b_i`` is ``x_i``: ``|1>`` is ``z = -1``. The
coefficients are divided by ``scale``, the largest of them, so the circuit's
angles stay in a fixed range, and ``scale * ising + offset`` gives back the
QUBO's energy exactly.

Qiskit and Aer are little-endian: basis state ``k`` has bit ``(k >> i) & 1`` on
qubit ``i``, which is variable ``i`` here.
"""

from __future__ import annotations

import hashlib
from dataclasses import dataclass

import numpy as np

from quantic.encoding.qubo import Qubo


@dataclass(frozen=True, eq=False)
class Ising:
    h: np.ndarray
    J: np.ndarray
    scale: float
    offset: float
    dynamic_range: float

    @property
    def n(self) -> int:
        return int(self.h.size)

    def energy(self, bits) -> float:
        """The QUBO's energy at ``bits``, computed through the Ising form."""
        z = 1.0 - 2.0 * np.asarray(bits, dtype=float)
        return float(self.scale * (self.h @ z + z @ self.J @ z) + self.offset)


def to_ising(qubo: Qubo) -> Ising:
    q = qubo.Q
    n = qubo.n_vars
    diag = np.diag(q).copy()
    upper = np.triu(q, 1)
    h = -diag / 2.0 - (upper + upper.T).sum(axis=1) / 4.0
    j = upper / 4.0
    offset = float(qubo.constant + diag.sum() / 2.0 + upper.sum() / 4.0)
    coefs = np.concatenate([np.abs(h), np.abs(j[np.triu_indices(n, 1)])])
    nonzero = coefs[coefs > 0.0]
    scale = float(nonzero.max()) if nonzero.size else 1.0
    dynamic_range = float(nonzero.max() / nonzero.min()) if nonzero.size else 1.0
    return Ising(h=h / scale, J=j / scale, scale=scale, offset=offset,
                 dynamic_range=dynamic_range)


def basis_energies(qubo: Qubo) -> np.ndarray:
    """The QUBO energy of every basis state, built one variable at a time.

    Adding variable ``i`` doubles the table: a state with bit ``i`` set costs the
    same state without it, plus ``Q_ii``, plus ``Q_ji`` for each lower bit ``j``
    it has set. That field is itself built by doubling, so the whole table costs
    about ``2**(n+1)`` additions, not ``n**2 * 2**n``.
    """
    q = qubo.Q
    table = np.array([float(qubo.constant)])
    for i in range(qubo.n_vars):
        field = np.zeros(1)
        for j in range(i):
            field = np.concatenate([field, field + q[j, i]])
        table = np.concatenate([table, table + q[i, i] + field])
    return table


def phases(qubo: Qubo, ising: Ising) -> np.ndarray:
    """Each basis state's scaled Ising energy: the diagonal of the cost operator."""
    return (basis_energies(qubo) - ising.offset) / ising.scale


def qubo_hash(qubo: Qubo) -> str:
    digest = hashlib.sha256()
    digest.update(np.ascontiguousarray(qubo.Q, dtype=np.float64).tobytes())
    digest.update(repr(float(qubo.constant)).encode("utf-8"))
    digest.update(repr(qubo.registry.keys).encode("utf-8"))
    return digest.hexdigest()
```

`src/quantic/solvers/quantum/statevector.py`:

```python
"""Exact QAOA on a numpy statevector -- M5 design section 5.3.

The cost layer ``exp(-i gamma H)`` is diagonal in the computational basis, so
it is one elementwise phase from the precomputed Ising energies. The mixer is
``RX(2 beta)`` on each qubit, one pass over the state per qubit. That costs
``O(p n 2**n)``, where simulating the circuit gate by gate costs a pass per
ZZ term, ``O(p n**2 2**n)``. ``tests/solvers/quantum/test_train.py`` checks
the two agree.
"""

from __future__ import annotations

import numpy as np

from quantic.encoding.qubo import Qubo
from quantic.solvers.quantum.ising import Ising, basis_energies


def _mix(state: np.ndarray, beta: float, n: int) -> None:
    c, s = np.cos(beta), np.sin(beta)
    for i in range(n):
        view = state.reshape(-1, 2, 2**i)
        a0 = view[:, 0, :].copy()
        a1 = view[:, 1, :].copy()
        view[:, 0, :] = c * a0 - 1j * s * a1
        view[:, 1, :] = c * a1 - 1j * s * a0


def qaoa_state(phase: np.ndarray, gammas, betas) -> np.ndarray:
    size = int(phase.size)
    n = size.bit_length() - 1
    if size != 2**n:
        raise ValueError(f"the phase table has {size} entries, not a power of two")
    state = np.full(size, 1.0 / np.sqrt(size), dtype=np.complex128)
    for gamma, beta in zip(gammas, betas, strict=True):
        state *= np.exp(-1j * float(gamma) * phase)
        _mix(state, float(beta), n)
    return state


class Landscape:
    """One QUBO's energies, sorted once, for the exact CVaR of any state."""

    def __init__(self, qubo: Qubo, ising: Ising) -> None:
        energy = basis_energies(qubo)
        self.phase = (energy - ising.offset) / ising.scale
        self.order = np.argsort(energy, kind="stable")
        self.sorted = energy[self.order]
        self.minimum = float(self.sorted[0])

    def cvar(self, probs: np.ndarray, alpha: float) -> float:
        """Mean energy of the lowest ``alpha`` of the probability mass."""
        mass = probs[self.order]
        cum = np.cumsum(mass)
        m = min(int(np.searchsorted(cum, alpha)), mass.size - 1)
        head = float(mass[:m] @ self.sorted[:m])
        before = float(cum[m - 1]) if m else 0.0
        return (head + (alpha - before) * float(self.sorted[m])) / alpha
```

```python
"""CVaR-QAOA angles, trained on the noiseless statevector -- M5 design 5.2-5.3.

The start is the linear ramp and COBYLA is deterministic, so the same QUBO,
depth, alpha and iteration cap always give the same angles. They are trained
once and shared by every backend (decision D3).
"""

from __future__ import annotations

import time
from dataclasses import dataclass

import numpy as np
from scipy.optimize import minimize

from quantic.encoding.qubo import Qubo
from quantic.solvers.quantum.ising import to_ising
from quantic.solvers.quantum.statevector import Landscape, qaoa_state

DELTA = 0.75
ANGLE_RULE = f"linear-ramp-{DELTA}"
_RHOBEG = 0.25


@dataclass(frozen=True)
class Angles:
    gammas: tuple[float, ...]
    betas: tuple[float, ...]
    cvar: float
    n_evals: int
    train_s: float

    def to_json(self) -> dict:
        return {"gammas": list(self.gammas), "betas": list(self.betas), "cvar": self.cvar,
                "n_evals": self.n_evals, "train_s": self.train_s}

    @classmethod
    def from_json(cls, body: dict) -> Angles:
        return cls(gammas=tuple(float(g) for g in body["gammas"]),
                   betas=tuple(float(b) for b in body["betas"]),
                   cvar=float(body["cvar"]), n_evals=int(body["n_evals"]),
                   train_s=float(body["train_s"]))


def initial_angles(reps: int) -> tuple[np.ndarray, np.ndarray]:
    k = (np.arange(reps) + 0.5) / reps
    return k * DELTA, (1.0 - k) * DELTA


def train(qubo: Qubo, *, reps: int, alpha: float, maxiter: int) -> Angles:
    if not 0.0 < alpha <= 1.0:
        raise ValueError(f"alpha must be in (0, 1], got {alpha!r}")
    if reps < 1 or maxiter < 1:
        raise ValueError(f"reps and maxiter must be at least 1, got {reps}, {maxiter}")
    started = time.perf_counter()
    land = Landscape(qubo, to_ising(qubo))

    def objective(x: np.ndarray) -> float:
        state = qaoa_state(land.phase, x[:reps], x[reps:])
        return land.cvar(np.abs(state) ** 2, alpha)

    gammas, betas = initial_angles(reps)
    found = minimize(objective, np.concatenate([gammas, betas]), method="COBYLA",
                     options={"maxiter": maxiter, "rhobeg": _RHOBEG})
    return Angles(
        gammas=tuple(float(v) for v in found.x[:reps]),
        betas=tuple(float(v) for v in found.x[reps:]),
        cvar=float(found.fun), n_evals=int(found.nfev),
        train_s=time.perf_counter() - started,
    )
```

```python
"""The QAOA circuit at given angles, for routing and for real or noisy sampling.

``RZ(2 gamma h_i)`` is ``exp(-i gamma h_i Z_i)``, ``RZZ(2 gamma J_ij)`` is
``exp(-i gamma J_ij Z_i Z_j)`` and ``RX(2 beta)`` is ``exp(-i beta X)``: the same
unitary as ``statevector.qaoa_state``.
"""

from __future__ import annotations

import numpy as np
from qiskit import QuantumCircuit

from quantic.solvers.quantum.ising import Ising


def qaoa_circuit(ising: Ising, gammas, betas, *, measure: bool = True) -> QuantumCircuit:
    n = ising.n
    if n == 0:
        raise ValueError("a QUBO with no variables has no circuit")
    circuit = QuantumCircuit(n)
    circuit.h(range(n))
    rows, cols = np.nonzero(ising.J)
    for gamma, beta in zip(gammas, betas, strict=True):
        for i in range(n):
            if ising.h[i] != 0.0:
                circuit.rz(2.0 * float(gamma) * float(ising.h[i]), i)
        for i, j in zip(rows, cols, strict=True):
            circuit.rzz(2.0 * float(gamma) * float(ising.J[i, j]), int(i), int(j))
        circuit.rx(2.0 * float(beta), range(n))
    if measure:
        circuit.measure_all()
    return circuit
```

```python
"""Where a QAOA circuit's shots come from -- M5 design section 6."""

from __future__ import annotations

from collections.abc import Mapping

import numpy as np
from qiskit import QuantumCircuit, transpile

from quantic.encoding.qubo import Qubo
from quantic.solvers.quantum.circuit import qaoa_circuit
from quantic.solvers.quantum.ising import Ising, phases, to_ising
from quantic.solvers.quantum.statevector import qaoa_state
from quantic.solvers.quantum.train import Angles

OPTIMIZATION_LEVEL = 3


def bits_from_counts(counts: Mapping[str, int], n: int) -> np.ndarray:
    """One row per shot, variable ``i`` in column ``i``.

    Qiskit writes clbit 0 rightmost, and ``measure_all`` puts qubit ``i`` on
    clbit ``i``.
    """
    rows = []
    for key, count in sorted(counts.items()):
        text = key.replace(" ", "")
        if len(text) != n:
            raise ValueError(f"a count key {key!r} does not have {n} bits")
        row = np.array([int(text[n - 1 - i]) for i in range(n)], dtype=np.int8)
        rows.append(np.repeat(row[None, :], int(count), axis=0))
    return np.concatenate(rows) if rows else np.zeros((0, n), dtype=np.int8)


def sample_ideal(qubo: Qubo, angles: Angles, shots: int, seed: int) -> np.ndarray:
    ising = to_ising(qubo)
    probs = np.abs(qaoa_state(phases(qubo, ising), angles.gammas, angles.betas)) ** 2
    probs /= probs.sum()
    picks = np.random.default_rng(seed).choice(probs.size, size=shots, p=probs)
    return ((picks[:, None] >> np.arange(ising.n)[None, :]) & 1).astype(np.int8)


def fake_backend(device: str):
    from qiskit_ibm_runtime.fake_provider import FakeProviderForBackendV2

    provider = FakeProviderForBackendV2()
    name = "fake_" + device.removeprefix("ibm_")
    try:
        return provider.backend(name)
    except Exception as exc:  # QiskitBackendNotFoundError, whatever its module
        known = sorted(b.name for b in provider.backends())
        raise KeyError(f"no fake twin {name!r} for device {device!r}; known: {known}") from exc


def route(ising: Ising, angles: Angles, backend, *, seed_transpiler: int = 0) -> QuantumCircuit:
    circuit = qaoa_circuit(ising, angles.gammas, angles.betas, measure=True)
    return transpile(circuit, backend, optimization_level=OPTIMIZATION_LEVEL,
                     seed_transpiler=seed_transpiler)


def routed_stats(routed: QuantumCircuit) -> tuple[int, int]:
    two = sum(1 for inst in routed.data
              if inst.operation.num_qubits == 2 and inst.operation.name != "barrier")
    return int(routed.depth()), int(two)


def sample_noisy(routed: QuantumCircuit, backend, shots: int, seed: int) -> np.ndarray:
    from qiskit_aer import AerSimulator

    simulator = AerSimulator.from_backend(backend)
    counts = simulator.run(routed, shots=shots, seed_simulator=seed).result().get_counts()
    return bits_from_counts(counts, routed.num_clbits)
```

```python
"""QAOA behind the ``QuboSampler`` interface -- M5 design section 6.

Every shot goes through ``run_sampler`` as one batch, so decoding,
classification and scoring are the M4 samplers' own. The energy of a shot is
the QUBO's at its bits; QAOA reports no energy of its own.
"""

from __future__ import annotations

import dataclasses

import numpy as np

from quantic.encoding.encode import EncodedInstance
from quantic.solvers.base import Budget, Result
from quantic.solvers.qubo.sampler import (
    STUDY_ZETA_BITS, QuboSampler, energies, run_sampler,
)
from quantic.solvers.quantum.backends import (
    fake_backend, route, routed_stats, sample_ideal, sample_noisy,
)
from quantic.solvers.quantum.ising import to_ising
from quantic.solvers.quantum.train import Angles


class QaoaSampler(QuboSampler):
    backend_name = ""

    def __init__(self, encoding: str, *, seed: int = 0, zeta_bits: int = STUDY_ZETA_BITS,
                 angles: Angles, shots: int, device: str | None = None) -> None:
        super().__init__(encoding, seed=seed, zeta_bits=zeta_bits)
        self.angles, self.shots, self.device = angles, shots, device
        self.extra: dict = {}

    def prepare(self, enc: EncodedInstance) -> None:
        """Work done once per run, before the shots: routing, for instance."""

    def sample(self, enc: EncodedInstance, shots: int, seed: int) -> np.ndarray:
        raise NotImplementedError

    def solve_encoded(self, enc: EncodedInstance, budget: Budget | None = None) -> Result:
        if enc.layout.encoding_name != self.encoding.name:
            raise ValueError(
                f"{self.name} was built for {self.encoding.name!r} and given an "
                f"instance encoded with {enc.layout.encoding_name!r}"
            )
        self.prepare(enc)

        def draw(bqm, reads, seed):
            bits = self.sample(enc, reads, seed)
            return bits, energies(enc.qubo, bits)

        result = run_sampler(self.name, enc, Budget(max_samples=self.shots), self.seed,
                             draw, one_batch=True)
        detail = {**result.detail, "backend": self.backend_name, "device": self.device,
                  "shots": self.shots, **self.extra}
        return dataclasses.replace(result, detail=detail)


class QaoaIdeal(QaoaSampler):
    name = "qaoa_ideal"
    backend_name = "ideal"

    def sample(self, enc, shots, seed):
        return sample_ideal(enc.qubo, self.angles, shots, seed)


class QaoaNoisy(QaoaSampler):
    name = "qaoa_noisy"
    backend_name = "noisy"

    def prepare(self, enc):
        if self.device is None:
            raise ValueError("qaoa_noisy needs the device whose fake twin it simulates")
        self.fake = fake_backend(self.device)
        self.routed = route(to_ising(enc.qubo), self.angles, self.fake)
        depth, two = routed_stats(self.routed)
        self.extra.update(routed_depth=depth, routed_2q=two)

    def sample(self, enc, shots, seed):
        return sample_noisy(self.routed, self.fake, shots, seed)


class QaoaCollected(QaoaSampler):
    """Bits a real device returned, judged like any other shots."""

    name = "qaoa_ibm"
    backend_name = "ibm"

    def __init__(self, encoding: str, *, bits: np.ndarray, **kw) -> None:
        super().__init__(encoding, **kw)
        self.bits = np.asarray(bits, dtype=np.int8)
        if len(self.bits) != self.shots:
            raise ValueError(f"{len(self.bits)} collected shots, {self.shots} expected")

    def sample(self, enc, shots, seed):
        return self.bits


QAOA_CLASSES = {c.name: c for c in (QaoaIdeal, QaoaNoisy, QaoaCollected)}
```

```python
"""The IBM quota ledger -- M5 design section 7.1, parent spec section 7.5.

The quota belongs to the account, not to a study, so the ledger lives outside
every store. A pending job counts at its ``max_execution_time``, which IBM
enforces, so even a runaway job cannot take the window past the cap. IBM's own
figure, when it can be read, is trusted only when it is the larger one.
"""

from __future__ import annotations

import json
import math
import os
from dataclasses import asdict, dataclass, replace
from pathlib import Path

QUOTA_CEILING_S = 300.0
WINDOW_S = 28 * 24 * 3600
PENDING = "pending"
DONE = "done"


class QuotaExhausted(RuntimeError):
    """Not enough of the window is left for one more job."""


@dataclass(frozen=True)
class Entry:
    job_id: str
    device: str
    task_key: str
    submitted_at: float
    max_execution_time_s: int
    state: str
    usage_s: float | None


def default_path() -> Path:
    override = os.environ.get("QUANTIC_QUOTA_PATH")
    return Path(override) if override else Path.home() / ".quantic" / "ibm-quota.json"


class Ledger:
    def __init__(self, path: Path | None = None) -> None:
        self.path = Path(path) if path is not None else default_path()

    def entries(self) -> list[Entry]:
        if not self.path.exists():
            return []
        body = json.loads(self.path.read_text(encoding="utf-8"))
        return [Entry(**job) for job in body["jobs"]]

    def pending(self) -> list[Entry]:
        return [e for e in self.entries() if e.state == PENDING]

    def _save(self, entries: list[Entry]) -> None:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self.path.with_suffix(self.path.suffix + ".tmp")
        tmp.write_text(json.dumps({"jobs": [asdict(e) for e in entries]}, indent=1),
                       encoding="utf-8")
        os.replace(tmp, self.path)

    def used_s(self, now: float) -> float:
        total = 0.0
        for e in self.entries():
            if now - e.submitted_at > WINDOW_S:
                continue
            total += e.max_execution_time_s if e.state == PENDING else (e.usage_s or 0.0)
        return total

    def allowance(self, *, cap_s: float, per_job_cap_s: float, min_job_s: float,
                  ibm_consumed_s: float | None, now: float) -> int:
        if cap_s > QUOTA_CEILING_S:
            raise ValueError(
                f"a cap of {cap_s} s is above the ceiling of {QUOTA_CEILING_S:g} s "
                "(M5 decision D4); change QUOTA_CEILING_S in code, not in config"
            )
        used = max(self.used_s(now), ibm_consumed_s or 0.0)
        left = cap_s - used
        if left < min_job_s:
            raise QuotaExhausted(
                f"{used:.1f} s of the {cap_s:g} s window are used and {max(left, 0):.1f} s "
                f"are left, less than one job's minimum of {min_job_s:g} s"
            )
        return int(math.floor(min(per_job_cap_s, left)))

    def add_pending(self, job_id: str, device: str, task_key: str,
                    max_execution_time_s: int, now: float) -> None:
        entry = Entry(job_id=job_id, device=device, task_key=task_key, submitted_at=now,
                      max_execution_time_s=int(max_execution_time_s), state=PENDING,
                      usage_s=None)
        self._save([*self.entries(), entry])

    def mark_done(self, job_id: str, usage_s: float) -> None:
        entries = self.entries()
        for i, e in enumerate(entries):
            if e.job_id == job_id:
                entries[i] = replace(e, state=DONE, usage_s=float(usage_s))
                self._save(entries)
                return
        raise KeyError(f"no job {job_id!r} in the ledger at {self.path}")
```

```python
"""IBM Quantum behind a small interface -- M5 design section 7.3.

``RuntimeClient`` is the account; ``LocalClient`` is the same calls in Qiskit
Runtime's local mode against a fake device, for the tests and the gate. Nothing
here decides whether a job may run: that is the ledger's and the gate's job.
"""

from __future__ import annotations

from typing import Protocol

from quantic.solvers.quantum.backends import fake_backend

_USAGE_KEYS = ("usage_consumed_seconds",)


class NoAccount(RuntimeError):
    """No IBM Quantum account is saved on this machine."""


class JobFailed(RuntimeError):
    """IBM reports the job failed or was cancelled."""


def consumed_from_usage(answer) -> float | None:
    """Seconds consumed in the window, from ``service.usage()``, or ``None``.

    The shape of that answer is IBM's; a key that is missing or unreadable is
    ``None``, so the ledger falls back to its own count and never to zero.
    """
    if not isinstance(answer, dict):
        return None
    for key in _USAGE_KEYS:
        if key in answer:
            try:
                return float(answer[key])
            except (TypeError, ValueError):
                return None
    return None


class IbmClient(Protocol):
    def consumed_s(self) -> float | None: ...
    def backend(self, device: str): ...
    def submit(self, routed, shots: int, max_execution_time_s: int) -> str: ...
    def counts(self, job_id: str) -> dict[str, int]: ...
    def usage_s(self, job_id: str) -> float: ...
    def queue_s(self, job_id: str) -> float | None: ...


def _sampler(mode, max_execution_time_s: int):
    from qiskit_ibm_runtime.executor_sampler import Sampler

    return Sampler(mode=mode, options={"max_execution_time": int(max_execution_time_s)})


class RuntimeClient:
    def __init__(self) -> None:
        from qiskit_ibm_runtime import QiskitRuntimeService

        try:
            self.service = QiskitRuntimeService()
        except Exception as exc:  # AccountNotFoundError and its relatives
            raise NoAccount(
                "no IBM Quantum account is saved. Save one once with "
                "QiskitRuntimeService.save_account(channel='ibm_quantum_platform', "
                f"token=...). Qiskit said: {exc}"
            ) from exc
        self._backend = None

    def consumed_s(self) -> float | None:
        try:
            return consumed_from_usage(self.service.usage())
        except Exception:
            return None

    def backend(self, device: str):
        return self.service.backend(device)

    def use(self, backend) -> None:
        """The backend the next submissions go to; the lane sets it before each job."""
        self._backend = backend

    def submit(self, routed, shots: int, max_execution_time_s: int) -> str:
        if self._backend is None:
            raise RuntimeError("call use(backend) before submit")
        job = _sampler(self._backend, max_execution_time_s).run([routed], shots=shots)
        return job.job_id()

    def counts(self, job_id: str) -> dict[str, int]:
        job = self.service.job(job_id)
        try:
            result = job.result()
        except Exception as exc:
            raise JobFailed(f"job {job_id} failed: {exc}") from exc
        return dict(result[0].data.meas.get_counts())

    def usage_s(self, job_id: str) -> float:
        return float(self.service.job(job_id).usage())

    def queue_s(self, job_id: str) -> float | None:
        try:
            stamps = self.service.job(job_id).metrics().get("timestamps", {})
            from datetime import datetime

            created = datetime.fromisoformat(stamps["created"].replace("Z", "+00:00"))
            running = datetime.fromisoformat(stamps["running"].replace("Z", "+00:00"))
            return (running - created).total_seconds()
        except Exception:
            return None


class LocalClient:
    def __init__(self, *, usage_per_job_s: float = 2.0, consumed: float | None = None,
                 fail: tuple[str, ...] = ()) -> None:
        self.usage_per_job_s, self.consumed, self.fail = usage_per_job_s, consumed, set(fail)
        self.submitted: list[tuple[str, int]] = []
        self._jobs: dict[str, object] = {}
        self._backend = None

    def consumed_s(self) -> float | None:
        """Grows with the jobs run, as IBM's figure would; ``None`` stays ``None``."""
        if self.consumed is None:
            return None
        return self.consumed + self.usage_per_job_s * len(self.submitted)

    def backend(self, device: str):
        self._backend = fake_backend(device)
        return self._backend

    def use(self, backend) -> None:
        self._backend = backend

    def submit(self, routed, shots: int, max_execution_time_s: int) -> str:
        job_id = f"job-{len(self.submitted)}"
        self._jobs[job_id] = _sampler(self._backend, max_execution_time_s).run(
            [routed], shots=shots)
        self.submitted.append((job_id, int(max_execution_time_s)))
        return job_id

    def counts(self, job_id: str) -> dict[str, int]:
        if job_id in self.fail:
            raise JobFailed(f"job {job_id} failed: told to fail")
        return dict(self._jobs[job_id].result()[0].data.meas.get_counts())

    def usage_s(self, job_id: str) -> float:
        return self.usage_per_job_s

    def queue_s(self, job_id: str) -> float | None:
        return 0.0
```

```python
"""Trained QAOA angles, cached in files beside the store -- M5 design section 5.4.

The store has one writer, the main process; workers that train or read angles
use this directory instead. A file is written whole or not at all.
"""

from __future__ import annotations

import hashlib
import json
import os
from importlib import metadata
from pathlib import Path

from quantic.solvers.quantum.train import ANGLE_RULE, Angles


class MissingAngles(RuntimeError):
    """A QAOA run's angles were never trained, or their training failed."""


def angle_key(qubo_hash: str, reps: int, alpha: float, maxiter: int) -> str:
    body = {"qubo": qubo_hash, "reps": reps, "alpha": alpha, "maxiter": maxiter,
            "rule": ANGLE_RULE, "numpy": metadata.version("numpy"),
            "scipy": metadata.version("scipy")}
    text = json.dumps(body, sort_keys=True, separators=(",", ":"))
    return hashlib.sha256(text.encode("utf-8")).hexdigest()


def angles_dir_for(store: Path) -> Path:
    store = Path(store)
    return store.with_name(store.stem + ".angles")


class AngleCache:
    def __init__(self, directory: Path) -> None:
        self.directory = Path(directory)

    def _path(self, key: str) -> Path:
        return self.directory / f"{key}.json"

    def get(self, key: str) -> Angles | None:
        path = self._path(key)
        if not path.exists():
            return None
        return Angles.from_json(json.loads(path.read_text(encoding="utf-8"))["angles"])

    def put(self, key: str, angles: Angles, meta: dict) -> None:
        self.directory.mkdir(parents=True, exist_ok=True)
        path = self._path(key)
        tmp = path.with_suffix(f".{os.getpid()}.tmp")
        tmp.write_text(json.dumps({"angles": angles.to_json(), **meta}, indent=1),
                       encoding="utf-8")
        os.replace(tmp, path)
```

```python
    def _train(self, row, task, instance):
        params = json.loads(task.params)
        enc = self.encoded(task, instance)
        key = angle_key(qubo_hash(enc.qubo), params["reps"], params["alpha"],
                        params["maxiter"])
        cache = self._angle_cache()
        angles = cache.get(key)
        cached = angles is not None
        if angles is None:
            angles = train(enc.qubo, reps=params["reps"], alpha=params["alpha"],
                           maxiter=params["maxiter"])
            cache.put(key, angles, {"qubo_hash": qubo_hash(enc.qubo), **params})
        row.update(
            store_status=OK, status="trained", n_vars=enc.n_vars,
            dynamic_range=dynamic_range_ratio(enc.qubo), angle_key=key,
            reps=params["reps"], total_s=angles.train_s,
            timings={"total_s": angles.train_s},
            detail={**angles.to_json(), "cached": cached,
                    "ising_dynamic_range": to_ising(enc.qubo).dynamic_range},
        )
        return row, [], []

    def _qaoa(self, row, task, instance):
        params = json.loads(task.params)
        enc = self.encoded(task, instance)
        key = angle_key(qubo_hash(enc.qubo), params["reps"], params["alpha"],
                        params["maxiter"])
        angles = self._angle_cache().get(key)
        if angles is None:
            raise MissingAngles(f"no trained angles {key[:12]} for {task.solver} on "
                                f"{task.tier}-{task.dials}-{task.instance_seed}")
        sampler = QAOA_CLASSES[task.solver](
            task.encoding, seed=task.solver_seed, zeta_bits=task.zeta_bits,
            angles=angles, shots=task.max_samples, device=params.get("device"),
        )
        row["n_vars"] = enc.n_vars
        row["dynamic_range"] = dynamic_range_ratio(enc.qubo)
        result = sampler.solve_encoded(enc)
        out = fill_row(row, result, instance)
        d = result.detail
        out[0].update(backend=d["backend"], device=d["device"], angle_key=key,
                      reps=params["reps"], shots=d["shots"],
                      routed_depth=d.get("routed_depth"), routed_2q=d.get("routed_2q"))
        return out
```

```python
"""Which tasks are quantum, which need hardware, and which are too big to plan.

M5 design sections 2 and 6: a QUBO above ``max_qubits`` is never planned, and a

    return task.solver in _QUANTUM

class QuboSizes:
    def __init__(self) -> None:
        self.instances = InstanceCache()
        self._sizes: dict[tuple, int] = {}

    def n_vars(self, task: Task) -> int:
        key = (task.tier, task.dials, task.instance_seed, task.encoding, task.zeta_bits)
        if key not in self._sizes:
            instance = self.instances.get(task.tier, task.dials, task.instance_seed)
            self._sizes[key] = encode(instance, encoding_named(task.encoding),
                                      n_zeta_bits=task.zeta_bits).n_vars
        return self._sizes[key]


@dataclass(frozen=True)
class Capped:
    kept: list
    over_max: int
    over_noisy: int


def cap(jobs, settings: QuantumSettings | None, sizes: QuboSizes) -> Capped:
    if settings is None:
        return Capped(kept=list(jobs), over_max=0, over_noisy=0)
    kept, over_max, over_noisy = [], 0, 0
    for key, task in jobs:
        if is_quantum(task):
            n = sizes.n_vars(task)
            if n > settings.max_qubits:
                over_max += 1
                continue
            if task.kind == RUN and task.solver == "qaoa_noisy" and n > settings.noisy_max_qubits:
                over_noisy += 1
                continue
        kept.append((key, task))
    return Capped(kept=kept, over_max=over_max, over_noisy=over_noisy)
```

```python
                 ledger, now):
        self.store, self.settings, self.code = store, settings, code
        self.where, self.versions, self.now = where, versions, now
        self.angles = AngleCache(Path(angles_dir))
        self.client, self.ledger = client, ledger
        self.instances = InstanceCache()
        self.summary = HardwareSummary()

    def encoded(self, task: Task):
        instance = self.instances.get(task.tier, task.dials, task.instance_seed)
        enc = encode(instance, encoding_named(task.encoding), n_zeta_bits=task.zeta_bits)
        return instance, enc

    def angles_for(self, task: Task, enc):
        params = json.loads(task.params)
        key = angle_key(qubo_hash(enc.qubo), params["reps"], params["alpha"],
                        params["maxiter"])
        angles = self.angles.get(key)
        if angles is None:
            raise MissingAngles(f"no trained angles {key[:12]} for {task.tier}-"
                                f"{task.dials}-{task.instance_seed}")
        return key, params, angles

    def finish(self, task: Task, row: dict, job_id: str) -> None:
        """Collect ``job_id`` and replace the pending row with what it returned."""
        instance, enc = self.encoded(task)
        key, params, angles = self.angles_for(task, enc)
        started = time.perf_counter()
        try:
            counts = self.client.counts(job_id)
        except JobFailed as exc:
            usage = self.client.usage_s(job_id)
            row.update(store_status=ERROR, error=f"JobFailed: {exc}", qpu_s=usage,
                       total_s=usage)
            self.store.replace(row)
            self.ledger.mark_done(job_id, usage)
            self.summary.n_errors += 1
            self.summary.n_written += 1
            return
        bits = bits_from_counts(counts, enc.n_vars)
        result = QaoaCollected(task.encoding, seed=task.solver_seed or 0,
                               zeta_bits=task.zeta_bits, angles=angles,
                               shots=len(bits), bits=bits,
                               device=params["device"]).solve_encoded(enc)
        out, samples, trace = fill_row(row, result, instance)
        usage = self.client.usage_s(job_id)
        out.update(store_status=OK, qpu_s=usage, total_s=usage,
                   queue_s=self.client.queue_s(job_id), angle_key=key,
                   reps=params["reps"], shots=len(bits), backend="ibm",
                   device=params["device"], job_id=job_id, n_vars=enc.n_vars,
                   dynamic_range=dynamic_range_ratio(enc.qubo),
                   timings={"total_s": usage,
                            "collect_wall_s": time.perf_counter() - started})
        self.store.replace(out, samples, trace)
        self.ledger.mark_done(job_id, usage)
        self.summary.n_written += 1

    def submit(self, key: str, task: Task) -> None:
        instance, enc = self.encoded(task)
        angle, params, angles = self.angles_for(task, enc)
        q = self.settings
        allowance = self.ledger.allowance(
            cap_s=q.quota_cap_s, per_job_cap_s=q.per_job_cap_s, min_job_s=q.min_job_s,
            ibm_consumed_s=self.client.consumed_s(), now=self.now(),
        )
        backend = self.client.backend(params["device"])
        self.client.use(backend)
        routed = route(to_ising(enc.qubo), angles, backend)
        depth, two = routed_stats(routed)
        job_id = self.client.submit(routed, q.shots, allowance)
        self.ledger.add_pending(job_id, params["device"], key, allowance, now=self.now())
        row = blank_row(key, task, self.code, self.where, self.versions)
        row.update(store_status=PENDING, job_id=job_id, device=params["device"],
                   backend="ibm", angle_key=angle, reps=params["reps"], shots=q.shots,
                   routed_depth=depth, routed_2q=two, instance_hash=instance.content_hash,
                   notional=instance.notional())
        # replace, not write: under --repeat-hardware, or after a killed row, the
        # key may already be stored, and the new job's row must take its place.
        self.store.replace(row)
        self.finish(task, row, job_id)


def _task_of(row: dict) -> Task:
    fields = ("kind", "tier", "dials", "instance_seed", "solver", "encoding", "zeta_bits",
              "solver_seed", "budget_s", "max_samples", "params")
    return Task(**{f: row[f] for f in fields})


def run_hardware(tasks, *, store, settings, code, where, versions, angles_dir,
                 client=None, ledger=None, repeat: bool = False,
                 now=time.time) -> HardwareSummary:
    lane = _Lane(store=store, settings=settings, code=code, where=where,
                 versions=versions, angles_dir=angles_dir,
                 client=client if client is not None else RuntimeClient(),
                 ledger=ledger if ledger is not None else Ledger(), now=now)
    for row in lane.store.pending_hardware().iter_rows(named=True):
        lane.finish(_task_of(row), dict(row), row["job_id"])
        lane.summary.n_collected += 1
    done = set() if repeat else lane.store.identities("qaoa_ibm")
    for key, task in tasks:
        if task.identity() in done:
            lane.summary.n_skipped_done += 1
            continue
        if not lane.store.gate_passed(gate_for(task, settings).identity()):
            lane.summary.n_gate_refused += 1
            print(f"[hardware] no passed gate for {task.tier}-{task.dials}-"
                  f"{task.instance_seed} {task.encoding}: run the qaoa_noisy gate first",
                  flush=True)
            continue
        try:
            lane.submit(key, task)
        except QuotaExhausted as exc:
            lane.summary.stopped = str(exc)
            break
    return lane.summary
```

In `finish` after a resume, `row` comes from the store, so its dict-valued columns are JSON strings. `fill_row` overwrites `timings` and `detail`. It also overwrites `violations` whenever there is a feasible schedule; otherwise the pending row's `None` stays. Either way the row is valid for `replace`.

```python
def _choose_commit(runs: pl.DataFrame, commit: str | None) -> pl.DataFrame:
    """One commit's rows, plus every hardware row: hardware is never run twice."""
    hardware = pl.col("solver") == "qaoa_ibm"
    present = sorted(runs.filter(~hardware)["commit"].unique().to_list())
    if commit is not None:
        if commit not in present:
            raise CommitChoice(
                f"the store holds no rows from commit {commit!r}; it holds {present}"
            )
        return runs.filter((pl.col("commit") == commit) | hardware)
    if len(present) > 1:
        raise CommitChoice(
            f"the store holds rows from {len(present)} commits, {present}; pass "
            "--commit to choose one, since rows from different code do not belong "
            "in one table"
        )
    return runs


def matched_reads(table: pl.DataFrame) -> pl.DataFrame:
    quantum = table.filter(pl.col("solver").is_in(QUANTUM_SOLVERS))
    if quantum.is_empty():
        return quantum
    shots = quantum["max_samples"].drop_nulls().unique().to_list()
    samplers = table.filter(~pl.col("solver").is_in(QUANTUM_SOLVERS)
                            & pl.col("max_samples").is_in(shots))
    both = pl.concat([quantum, samplers], how="diagonal_relaxed")
    tts = [
        SIMULATED if r["solver"] in ("qaoa_ideal", "qaoa_noisy")
        else (f"{r['tts99_s']:.3g}s" if r["tts99_s"] is not None else "censored")
        for r in both.iter_rows(named=True)
    ]
    return both.with_columns(pl.Series("tts", tts)).select(
        "tier", "dials", "solver", "encoding", "max_samples", "n_runs",
        "p_success_0.01", "p_success_0.05", "gap_median", "feasibility", "tts",
    ).sort("tier", "dials", "solver", "encoding")


def qaoa_noise(scored_runs: pl.DataFrame) -> pl.DataFrame:
    rows = scored_runs.filter(pl.col("solver").is_in(QUANTUM_SOLVERS))
    if rows.is_empty():
        return rows.select("tier", "dials", "instance_seed", "encoding", "solver")
    return rows.group_by(["tier", "dials", "instance_seed", "encoding", "solver"],
                         maintain_order=True).agg(
        pl.len().alias("n_runs"),
        pl.col("ok_0.01").mean().alias("p_success_0.01"),
        (pl.col("n_feasible_samples").sum() / pl.col("n_samples").sum()).alias("feasibility"),
        pl.col("routed_depth").median().alias("routed_depth"),
        pl.col("routed_2q").median().alias("routed_2q"),
        pl.col("qpu_s").sum().alias("qpu_s"),
    ).sort("tier", "dials", "instance_seed", "encoding", "solver")

        "ising_dynamic_range": pl.Float64, "train_s": pl.Float64, "cvar": pl.Float64,
```
